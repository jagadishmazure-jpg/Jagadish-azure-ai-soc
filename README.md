# Azure AI SOC (agentic, multi-tenant, offline-first)

A reference build of an AI-assisted security operations centre on Microsoft Sentinel and Defender XDR
patterns: triage, investigation, ATT&CK mapping, threat-intel enrichment, behaviour baselines,
predictive risk and human-approved containment, for a fictional MSSP with three tenants.

Everything runs offline on synthetic data. No Azure subscription or API key is needed, and nothing in
this repository has been deployed.

This README is replaced by the full documentation as the build lands; see CHANGELOG.md.
