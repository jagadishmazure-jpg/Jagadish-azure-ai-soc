# detections

Detection as code: one KQL file per analytics rule plus shared metadata. The same files run offline through the KQL engine and are deployed (opt-in, disabled) by both IaC stacks. See [../docs/components/detections.md](../docs/components/detections.md).

| File | What it does |
|---|---|
| `rules.yaml` | Rule metadata: severity, tactics, techniques, schedule, prior, crossing, entities |
| `rules.json` | Generated by `aisoc rules-json` (queries embedded); read by Terraform and Bicep; drift-checked |
| `password-spray.kql` | Password spray against many accounts (T1110.003) |
| `success-after-spray.kql` | Successful sign-in from a spraying address (T1078.004, T1110.003) |
| `encoded-powershell.kql` | PowerShell with an encoded command (T1059.001) |
| `office-spawns-script.kql` | Office application starts a script interpreter (T1204.002, T1059.001) |
| `lsass-dump.kql` | LSASS memory dump (T1003.001) |
| `shadow-copy-delete.kql` | Volume shadow copies deleted (T1490) |
| `ti-c2-connection.kql` | Connection to a threat-intel address (T1071.001) |
| `ti-url-click.kql` | Click on a threat-intel domain (T1566.002) |
| `phish-click.kql` | Click on a link in a phishing message (T1566.002) |
| `inbox-forward-external.kql` | Mailbox rule forwards externally (T1114.003) |
| `mass-download.kql` | Mass file download (T1530) |
| `exfil-personal-cloud.kql` | Uploads to an external cloud destination (T1567.002) |
